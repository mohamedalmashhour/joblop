# Resident Job Low-Fidelity Wireframes

Status: Active controlled design phase
Architecture baseline: Resident Job Architecture Phase 1 v1.0
UX baseline: Resident Job UX Foundation
Implementation: Not authorized

## Rule

Wireframes are created one page at a time. Each page must complete its approval gate before the
next page begins.

Page 001 - Landing Page is the gold standard for the remaining wireframe phase.

All future pages must follow:

1. Frozen architecture reference.
2. Initial low-fidelity wireframe.
3. Self validation.
4. Product Design Review with scorecard.
5. Controlled revision if required.
6. Approval record.
7. Design Status Matrix update.
8. Stop and wait for approval before the next page.
