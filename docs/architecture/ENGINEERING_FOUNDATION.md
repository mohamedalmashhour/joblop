# Engineering Foundation

Resident Workforce OS starts as a TypeScript monorepo with separate app and package boundaries.

## Approved Applications

- Worker mobile shell: `apps/mobile`
- Employer portal shell: `apps/employer`
- Admin portal shell: `apps/admin`
- API shell: `apps/api`

## Approved Shared Packages

- `packages/design-system`
- `packages/ui`
- `packages/shared`
- `packages/config`
- `packages/auth`
- `packages/database`
- `packages/validation`
- `packages/notifications`
- `packages/observability`

## Boundary

No business implementation is included in the foundation scaffold.

G01 must begin only after this repository foundation is reviewed.
