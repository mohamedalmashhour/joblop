## 2. Approved Scope

The approved wireframe covers:

- employer operational dashboard purpose;
- urgent staffing attention band;
- shifts at risk;
- pending approvals;
- workers currently checked in;
- staffing, people, communications, finance, support, and organization-health summaries;
- conceptual dashboard widgets only;
- organization switching future-readiness;
- role-based visibility;
- employer-visible worker privacy boundaries;
- high-level billing summary boundaries;
- compliance reminder boundaries;
- AI assistant boundaries;
- mobile-first dashboard hierarchy;
- empty, loading, and error states;
- accessibility and international-readiness requirements.

- production security and privacy validation.

These are not Page 037 wireframe defects.
