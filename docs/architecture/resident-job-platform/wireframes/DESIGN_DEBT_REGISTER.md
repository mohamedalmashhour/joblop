# Resident Job Design Debt Register

Status: Active design governance artifact
Architecture baseline: Resident Job Architecture Phase 1 v1.0
UX baseline: Resident Job UX Foundation
Implementation: Not authorized

## Purpose

This register preserves useful design improvements that are not launch blockers. It prevents
future ideas from creeping into the current wireframe gate while making sure they are not lost.

Design debt entries may become future revisions, high-fidelity design tasks, or later release
improvements only after approval.

## Rules

- Do not modify approved wireframes to address design debt unless formally authorized.
- Do not use design debt as a reason to bypass current page gates.
- Do not turn future enhancements into implied launch functionality.
- Do not add production code from this register.
