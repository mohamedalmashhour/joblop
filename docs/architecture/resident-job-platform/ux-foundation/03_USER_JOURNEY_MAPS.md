# User Journey Maps

Status: Draft complete, awaiting UX Foundation approval
Architecture baseline: Resident Job Architecture Phase 1 v1.0
Implementation: Not authorized

## Purpose

Map the main user journeys before wireframes are created.

## Worker Journey

- Discover platform.
- Create account.
- Complete profile, documents, groups, payment data.
- Review available group offers.
- Apply or accept offer.
- Attend shift.
- Check in/out.
- Review timesheet and earnings.
- Receive payout status.

## Employer Journey

- Request staff.
- Choose staff group.
- Answer operational questionnaire.
- Review estimate and conditions.
- Submit for dispatch.
- Review AI/scheduler recommendation.
- Approve assigned worker.
- Monitor attendance.
- Approve timesheet.
- Receive invoice.

## Scheduler Journey

- Review open demand.
- Identify urgent gaps.
- Review AI recommendations and missing data.
- Resolve conflicts.
- Send offer.
- Confirm worker acceptance.
- Monitor shift progress.
- Handle replacements or exceptions.

## Admin Journey

- Monitor platform health.
- Review users, workers, employers, shifts, finance, compliance.
- Approve protected changes.
- Review audit and AI guardrails.
- Export internal reports.
