## 2. Approved Scope

Page 025 defines the authenticated worker Apply experience.

Approved capabilities at wireframe level:

- Submit a shift-specific worker application.
- Save an application draft.
- Review the application lifecycle.
- Confirm application-specific information before submission.
- Collect only shift-specific inputs.
- Display compensation summary and compensation-state labels.
- Summarize requirement gaps safely.
- Preserve worker-private notes and draft information.
- Clarify employer or authorized reviewer visibility.
- Support withdrawal of an application.
- Clarify that withdrawal of an application is not cancellation of an accepted assignment.
- Keep AI assistance advisory and non-operative.

## 3. Approval Basis

The approved revision satisfies all documented owner conditions:

- Application and assignment remain separate.
- Employer review boundaries are explicit.
- Worker consent is informed.
- Withdrawal is governed independently.
- Compensation is truthful.
- Privacy is preserved.
- AI cannot submit, negotiate, or rank unfairly.
- No governance, legal, or operational risk remains at wireframe level.

## 4. Explicit Boundaries

Apply does not:

- Select the worker.
- Assign the worker.
- Create an assignment offer.
- Accept an assignment.
- Create an employment contract.
- Confirm attendance.
- Create payroll.
- Guarantee response.
- Guarantee interview.
- Guarantee selection.
- Guarantee employment.
- Negotiate compensation.
- Modify worker answers through AI.
- Re-collect full profile or compliance information.
