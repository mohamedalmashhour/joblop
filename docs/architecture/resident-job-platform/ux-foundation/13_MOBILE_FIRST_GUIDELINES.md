# Mobile-First Guidelines

Status: Draft complete, awaiting UX Foundation approval
Architecture baseline: Resident Job Architecture Phase 1 v1.0
Implementation: Not authorized

## Purpose

Define how pages should adapt for workers and managers using phones during real operations.

## Principles

- Worker flows are phone-first.
- Emergency actions must be obvious.
- Forms are broken into short steps.
- Calendars show today first, then future.
- Group selection appears before offer discovery.
- Approval and status are always visible.

## Patterns

- Bottom navigation for worker app.
- Sticky primary action where appropriate.
- Swipe or segmented filters for group/date/urgency.
- Cards over dense tables.
- Progressive disclosure for compliance and finance details.

## Avoid

- Tiny table grids
- Hidden CTAs
- Unlabeled demo data
- Long paragraphs in urgent flows
