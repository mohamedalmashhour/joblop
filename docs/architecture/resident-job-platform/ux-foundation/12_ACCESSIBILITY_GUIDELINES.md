# Accessibility Guidelines

Status: Draft complete, awaiting UX Foundation approval
Architecture baseline: Resident Job Architecture Phase 1 v1.0
Implementation: Not authorized

## Purpose

Ensure Resident Job can be used by workers, managers, schedulers, and admins with varied abilities and devices.

## Requirements

- WCAG 2.2 AA target.
- Minimum touch target 44px.
- Keyboard navigable desktop flows.
- Visible focus states.
- Color is never the only signal.
- Readable text sizes.
- Clear errors and recovery instructions.
- Screen-reader labels for icons and controls.

## Content

- Plain language
- Short form steps
- No hidden critical instructions
- Status labels use text plus visual state

## Testing

- Mobile viewport
- Keyboard navigation
- Screen reader smoke test
- Contrast checks
- Error-state checks
